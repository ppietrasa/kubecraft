The /30 mask on 10.1.1.200 puts it in the 10.1.1.200 - 10.1.1.203 network. Only
last 2 bits of IP addr are left to the hosts.  Binary 11 is 3. So we have 0, 1,
2, 3. In our case .200, .201, .202, .203.  Of these only only 10.1.1.201,
10.1.1.202 are assignable. The 10.1.1.200 is the network.  The 10.1.1.203 is
the broadcast address.
